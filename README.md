# EV Market & Orders Data Analysis

This repository contains an Electric Vehicle (EV) Market & Orders data analysis project. The project uses a raw dataset, a Jupyter Notebook, and a written PDF report to explore, clean, analyze, and summarize EV market and order-related data.

## Project Overview

The purpose of this project is to analyze EV Market & Orders data to identify useful patterns, trends, and insights. The analysis process includes data cleaning, exploratory data analysis, visualizations, and written findings presented in an assignment-style report.

## Repository Files

| File | Description |
|---|---|
| `Dataset.csv` | The raw dataset used for the EV Market & Orders analysis. This file contains the original data before cleaning and analysis. |
| `EV_Markets_and_Orders_Data_Analysis.ipynb` | The Jupyter Notebook containing the assignment work, including Python code, data cleaning steps, analysis, and visualizations. |
| `EV Market and Orders Data Analysis.pdf` | The final written report containing the findings, results, and interpretation of the data cleaning and analysis process in an assignment-style format. |

## Analysis Workflow

1. **Data Loading**  
   The raw dataset is loaded from `Dataset.csv` into the Jupyter Notebook.

2. **Data Cleaning**  
   The dataset is checked and cleaned to handle issues such as missing values, incorrect data types, duplicates, and inconsistent entries.

3. **Exploratory Data Analysis**  
   The cleaned data is explored to understand market patterns, order behavior, and important trends in the EV dataset.

4. **Data Visualization**  
   Charts and visual summaries are created to support the analysis and make the findings easier to understand.

5. **Findings and Reporting**  
   The final insights and results are summarized in the PDF report: `EV Market and Orders Data Analysis.pdf`.

## How to Use This Repository

### 1. Clone the Repository

```bash
git clone https://github.com/khanaalifian-design/EV-Market-Orders-Data-Analysis-Task.git
cd EV-Market-Orders-Data-Analysis-Task
```

### 2. Open the Jupyter Notebook

Open the notebook file:

```bash
jupyter notebook EV_Markets_and_Orders_Data_Analysis.ipynb
```

Alternatively, you can open it using JupyterLab, Google Colab, or Visual Studio Code.

### 3. Run the Analysis

Run the notebook cells in order to reproduce the data cleaning, analysis, and visualizations.

Make sure `Dataset.csv` is in the same project folder as the notebook so the dataset can be loaded correctly.

### 4. Read the Final Report

Open the PDF file to view the completed findings and results:

```text
EV Market and Orders Data Analysis.pdf
```
